# Glowvy Beauty Center 🌸

A modern, responsive, and luxury web application for **Glowvy Beauty Center** located in London[cite: 1]. Designed with an elegant aesthetic to showcase salon services, curated packages, customer reviews, and an interactive reservation system.

![Glowvy Preview](./src/assets/og-image.jpg)

## ✨ Features

- **Hero Slider**: Interactive carousel with smooth animations and dynamic quote transitions.
- **Dynamic Services Showcase**: 12 curated treatments categorized with paginated navigation and Lucide iconography.
- **Curated Packages**: Tiered service bundles designed for regular care and seasonal refreshes.
- **Client Stories (Testimonials)**: Realistic social review carousel with interactive auto-sliding and indicators.
- **Reservation & Inquiries**: Split-section booking form paired with an interactive FAQ accordion.
- **Performance & SEO Ready**:
   - Semantic HTML5 structure with comprehensive Open Graph and Twitter Card tags.
   - LocalBusiness JSON-LD Schema markup for local London SEO.
   - Optimized image handling with native lazy loading.
   - Fully responsive layout across mobile, tablet, and desktop screens.

## 🛠️ Built With

- **Core**: Semantic HTML5, Vanilla JavaScript (ES6 Modules)
- **Styling**: Sass / SCSS (BEM Architecture, CSS Custom Properties, Modular Mixins)
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **Tooling & Bundler**: [Vite](https://vitejs.dev/)

## 📁 Project Structure


## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:

   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/<repo-name>.git
   cd <repo-name>
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start local development server:

   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
